# Today's session

1. Run `make today` (today's slice of the schedule with [x]/[ ] status, overdue items, #redo list) and `make progress`.
2. Reply in at most ~10 lines:
   - Today's items, each linked (look the link up on its line in `modules/NN-*/problems.md`).
   - Overdue: the count and the hours. More than ~2 h behind → suggest `make replan` and ask before running it.
   - Sunday → the review hour comes first: pick 2–3 `#redo` items plus the oldest unreviewed `practice/MISTAKES.md` lines.
   - Saturday, from 31 Oct → the mock comes first: offer `/mock`.
   - If today has a **Read** item: the NOTES section's title plus one line on what it unlocks.
3. End with exactly one next action, concrete enough to start immediately, e.g.
   "Open modules/06-two-pointers-window-prefix/NOTES.md section 2, then copy practice/_template.cpp to practice/06/0003-longest-substring.cpp."

Never include solutions or approach hints for today's problems.
