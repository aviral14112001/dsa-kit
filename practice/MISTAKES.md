# Mistakes log

One line per miss, written the same day: `date · problem · type · the signal or fix`. The Sunday review starts here, and
every ~4 mocks, count the types: the most frequent one is your weakest skill.

Types: **recognition** (didn't see the pattern) · **template** (knew it, fumbled the code) · **bug** (off-by-one, overflow,
null, reset) · **complexity** · **communication** · **time**
